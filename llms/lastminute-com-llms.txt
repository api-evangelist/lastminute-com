# lastminute.com

> lastminute.com N.V. (SIX Swiss Exchange: LMN) is a European travel-tech group and
> the regional leader in dynamic holiday packages. It operates a portfolio of online
> travel brands selling flights, hotels and packaged travel across a global network.
> lastminute.com runs a partner-facing API portal at developers.lastminute.com, but
> its API reference content is gated behind a workspace sign-in — as of 2026-07-19
> there is no publicly retrievable OpenAPI description, client SDK, or self-service
> developer onboarding path.

Generated by the API Evangelist enrichment pipeline from the catalog profile at
all/lastminute-com/apis.yml. Not published by lastminute.com.

## Developer

- [Developer portal (lmn API Portal)](https://developers.lastminute.com/): Stoplight-hosted
  workspace `lmnuserexperience`. Reachable publicly, but no project is anonymously
  readable — API documentation requires sign-in, so this is a partner/private surface.
- [GitHub organization](https://github.com/lastminutedotcom): 10 public repositories.
  These are engineering samples and internal tooling (a Cloudflare monitoring tool,
  Jenkins pipeline metrics, a KrakenD/Kafka Lambda, Spring OAuth2 SSO and React Native
  examples, hiring katas) — not client libraries for a lastminute.com API.
- [Technology blog](https://technology.lastminute.com/): active engineering blog,
  including the "Our Tech Ecosystem" series on architecture, backend/frontend stack
  (Java, Kotlin, Spring Boot, React, TypeScript, Next.js), Kafka and DDD, DevOps and
  observability on Kubernetes, data/ML, and infrastructure.
- [Technology blog feed](https://technology.lastminute.com/rss.xml)
